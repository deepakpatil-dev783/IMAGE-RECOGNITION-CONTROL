# Data Directory

Place your product images here in the following structure:

```
data/raw/
    PASS/
        product_001.jpg
        product_002.jpg
        ...
    DEFECT/
        defect_001.jpg
        defect_002.jpg
        ...
```

- **PASS/**: Images of products that meet quality standards
- **DEFECT/**: Images of products with defects or quality issues

Supported formats: JPG, JPEG, PNG, BMP, TIFF

Recommended: At least 500 images per class for good model performance.
